### 1. Постановка задачи 

#### Задание 1. 

Вычислить значение выражения при различных вещественных типах данных (`float` и `double`): 
((a + b)<sup>2</sup> − (a<sup>2</sup> + 2ab)) / b<sup>2</sup>, при \(а=1000\), \(b=0.0001\).

Вычисления выполнять с использованием промежуточных переменных. Сравнить и объяснить полученные результаты.
#### Задание 2.
Вычислить значения выражений и объяснить полученные результаты:
1. `--m-++n`
2. `m*n<n++`
3. `n-- > m++`

### 2. Программа решения задания 1

``` cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
// вычисления с типом float 
    float a=1000.0f;
    float b=0.0001f;
    
    float ab1 = pow(a+b, 2);
    float a1 = pow(a,2);
    float ab2 = 2*a*b;
    float chisl = ab1 - (a1 + ab2);
    float znam = pow(b,2);
    float res = chisl/znam;

    cout << "Float: " << res << endl;

    // вычисления с типом double
    double ad = 1000.0;
    double bd = 0.0001;

    double adbd1 = pow(ad+bd, 2);
    double ad1 = pow(ad,2);
    double adbd2 = 2*ad*bd;
    double chisl1 = adbd1 - (ad1 + adbd2);
    double znam1 = pow(bd,2);
    double res1 = chisl1/znam1;
    
    cout << "Double: " << res1 << "\n";

    return 0;
}

```
### 3. Результаты  работы программы для данных типа float 

6.25e+06

### 4. Результаты  работы программы для данных типа double

1.00117

### 5. Объяснение результатов

При вычислении выражения с типом float результат значительно отличается от математически ожидаемого значения, равного 1. Это происходит из-за ограниченной точности типа float, который занимает 4 байта. При сложении и вычитании близких по величине чисел возникает ошибка округления, которая особенно сильно влияет на результат при делении на маленькое число b^2.

Тип double занимает 8 байт и обеспечивает более высокую точность вычислений. Поэтому полученный результат значительно ближе к математическому значению 1.

### 6. 	Программа решения задания2

``` cpp
#include <iostream>
using namespace std;
int main() { 
    int m = 3; int n = 5;
    // Задание 1: - -m - ++n
    int result1 = -(-m) - ++n;
    cout << "1) - -m - ++n = " << result1 << endl;

    // Задание 2: m * n < n++
    m = 3;
    n = 5;
    bool result2 = m * n < n++;
    cout << "2) m * n < n++ = " << result2 << endl;

    // Задание 3: n-- > m++
    m = 3;
    n = 5;
    bool result3 = n-- > m++;
    cout << "3) n-- > m++ = " << result3 << endl;

    return 0;
}
```
### 7. 	Результаты  работы программы

1) - -m - ++n = -3
2) m * n < n++ = 0
3) n-- > m++ = 1

### 8. 	Объяснение результатов

1. Выражение - -m - ++n
Начальные значения: m = 3, n = 5.
Сначала вычисляется -m, в результате получается -3. Затем первый минус меняет знак числа на противоположный, поэтому получаем 3.
Оператор ++n увеличивает значение n на единицу до использования. Значение n изменяется с 5 на 6.
Выполняем вычитание: 3 - 6 = -3.

2. Выражение m * n < n++
Начальные значения: m = 3, n = 5.
Сначала вычисляется произведение m * n: 3 * 5 = 15.
Оператор n++ возвращает старое значение переменной n, равное 5, а затем увеличивает n до 6.
Сравниваем 15 < 5. Условие ложно, поэтому результат типа bool равен false, который при стандартном выводе отображается как 0.

3. Выражение n-- > m++
Начальные значения: m = 3, n = 5.
Оператор n-- возвращает старое значение n, равное 5, а затем уменьшает его до 4.
Оператор m++ возвращает старое значение m, равное 3, а затем увеличивает его до 4.
Сравниваем 5 > 3. Условие истинно, поэтому результат типа bool равен true, который при стандартном выводе отображается как 1.
