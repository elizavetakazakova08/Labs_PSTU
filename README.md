### 2. Программа решения задания 1

``` cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
// вычисления с типом float 
    float a=1000.0f;
    float b=0.0001f;
    
    float ab1 = pow(a+b, 2);
    float a1 = pow(a,2);
    float ab2 = 2*a*b;
    float chisl = ab1 - (a1 + ab2);
    float znam = pow(b,2);
    float res = chisl/znam;

    cout << "Float: " << res << endl;

    // вычисления с типом double
    double ad = 1000.0;
    double bd = 0.0001;

    double adbd1 = pow(ad+bd, 2);
    double ad1 = pow(ad,2);
    double adbd2 = 2*ad*bd;
    double chisl1 = adbd1 - (ad1 + adbd2);
    double znam1 = pow(bd,2);
    double res1 = chisl1/znam1;
    
    cout << "Double: " << res1 << "\n";

    return 0;
}

```

### 4. Результаты  работы программы для данных типа double

1.00117

### 5. Объяснение результатов

При вычислении выражения с типом float результат значительно отличается от математически ожидаемого значения, равного 1. Это происходит из-за ограниченной точности типа float, который занимает 4 байта. При сложении и вычитании близких по величине чисел возникает ошибка округления, которая особенно сильно влияет на результат при делении на маленькое число b^2.

Тип double занимает 8 байт и обеспечивает более высокую точность вычислений. Поэтому полученный результат значительно ближе к математическому значению 1.
